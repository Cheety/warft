# E-09 — Fact store

**Status:** ruled · **Source:** panel E-09 of the architecture overview, revision 2 (`workpod-plattform-leitstand.html`), carried over per AP-0.1. Translated under [the language ruling](language.md); the identifiers are untouched.

## Ruling

SCIP as the producer format — per language the existing indexer. Storage columnar as Parquet, partitioned by build target, keyed by file content + indexer version (G-03). The query embedded in the harness, read-only in the pod — no service, no network. Derived relations are computed by Soufflé in maintenance jobs and written back as further partitions.

## Rationale

1. **Why not Glean:** a stateful service per cell, a second storage technology and an operating surface of its own. Its gain — incremental at billions of facts — only pays off beyond the largest repository family this platform carries on day one. And it stays reachable: behind the same handle, not instead of it.
2. **Why not CodeQL:** the licence binds commercial use to GitHub's terms. An engine you are not allowed to ship is not an option — regardless of how good it is.
3. **Why not Kythe:** bound to Bazel, maintenance status open. SCIP is what has survived from that line as an exchange format in practice (G-06) — and a format outlives its tools.
4. **The same one binary.** The query lies as an embedded library in the harness from E-02 — statically linked, only larger. A query service would be a second process with a failure of its own, which V-01 has just spared the knowledge layer.
5. **Files have the properties V-05 demands:** backup is a daily snapshot, migration is a copy (V-03), distribution is a CoW snapshot with a warm page cache. Facts never leave the cell (E-07) — with files that is a mount, not a firewall rule.
6. **Judgements stay where they are:** in the append-only log of the cell (G-01, E-02). This ruling concerns the facts; the expiry mechanics via the content hash do not change.

## Overturned by

a measurement — if the incremental rebuild of the largest repository family blows the maintenance window, or the snapshot distribution breaks locality (V-02), Glean comes in behind the same query. The handle stays, the storage changes — that is exactly why `fact.query` is a capability and not a pass-through.
